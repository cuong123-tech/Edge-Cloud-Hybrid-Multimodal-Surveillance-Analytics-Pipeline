# Edge-Cloud Hybrid Multimodal Surveillance

POC: laptop cam → edge pose (tuần 2+) → hybrid LLM/VLM alerts (Telegram). Local-first; Docker ở cuối.

## Quick start (tuần 1)

1. Chạy **edge-inference** + **frontend** theo [docs/DEV_LOCAL.md](docs/DEV_LOCAL.md).
2. Mở http://localhost:5173 → Start → xác nhận WebSocket ack ~12/s.
